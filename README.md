# Photo Gallery (React + Vite + Tailwind 4)

A simple, responsive photo gallery built with React, Vite, and Tailwind CSS. It displays photos in a masonry layout (max 10 images per gallery) using the Picsum Photos API (no API key required).

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Features

- Masonry responsive layout (adapts to all screen sizes)
- Loads a new set of 10 photos on each search
- Shows max 10 images per gallery
- Loading, error, and empty states
- Cross-browser compatible (Chrome, Firefox, Opera, Safari, Edge)
